## 这是什么

一个 HTML 文件，双击即开。不注册、不联网、不上传——你写下的每一个字，都只留在这台设备的浏览器里。

它替两件事提供了地方：

> QUESTIONS THAT OUTLIVE THEIR ASKERS

### ✳ 伊甸园 · 个人问题

把还没想明白的问题种下来，给它时间。

- **状态流转**：待探索 → 正在想 → 想通了。问题不必急着开花。
- **笺记**：同一个问题可以反复回来写。首笺、续笺、三笺……想法是会长出来的，不是一次性结论。
- **✿ 花签**：一个问题被标成「想通了」之后，可以给它留一枚花签——想通的那一刻是什么样子，值得单独记下来。
- **随机回访**：点一下「↝ 随机回访」，花园会替你翻牌子。还没想完的问题更容易被翻到，想通了偶尔回来看看就好。
- **堆肥箱**：删掉的问题不会立刻消失，会在堆肥箱里躺三十天，变回土之前随时可以捞回来。

### ❦ 会饮篇 · 哲人之问

二十四道从原著里整理出来的问题，围坐下来，不急着赢得辩论，先把问题听清楚。

- **四类分席**：哲学 12 问（柏拉图对话录带 Stephanus 编号引注、亚里士多德）、科技 4 问（图灵、海德格尔、塞尔、维纳）、语言 4 问（克拉底鲁、维特根斯坦、索绪尔、洪堡）、社会学 4 问（涂尔干、韦伯、马克思、戈夫曼）。
- **多笺回答**：每道题都可以一答再答，回头看看自己当时怎么想。
- **我的存档**：遇到想留住的问题，收入档案；想清楚了再放回席间。
- **自拟题与自定义分类**：席间缺什么问题，可以自己添。

> 题目据原著整理，中文为译意或意译；标注发问者与出处，不代表逐字引文。

## 怎么打开

下载 `eden.html`，用浏览器打开即可。

部分浏览器在 `file://` 下会限制 localStorage（数据存不下）。如果页面提示存不了，起一个本地服务再打开：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/eden.html
```

## 数据与隐私

- 所有数据只存在**你自己浏览器的 localStorage** 里。没有账号，没有服务器，没有埋点。
- 页脚的 **↓ 导出备份** 会把个人问题、会饮篇回答和自定义分类打包成一个 JSON 文件；超过两周没备份，提醒会变红。
- **↑ 导入合并** 不是覆盖，是合并：按 id 去重，两台设备的花圃可以合到一起，一条都不丢。
- 删除走堆肥箱，三十天后自动清空。

## 设计

宋体衬线配等宽小字，纸面质感，两种时辰：

- **白天**是暖白的纸与苔绿；
- **夜间**是 `#0b0d10` 的底与 `#8fb3c9` 的光——这套配色来自另一个同样私人的项目。

尊重系统的 `prefers-reduced-motion` 设置；焦点、键盘与读屏标签都在。
